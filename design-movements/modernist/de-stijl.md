## Overview

De Stijl is a Dutch art and design movement which tried to establish harmony by means of the use of geometric shapes and well-balanced composition. One of the most popular interpretations of De Stijl features straight lines – both vertical and horizontal, rectangles, and limited color palette.

## Key characteristics

- Horizontal and vertical lines.
- Rectangles and areas of white space.
- Black lines with red, blue, or yellow accents.
- Asymmetrical arrangements that still feel balanced.

These characteristics are most familiar from Mondrian’s work. De Stijl included multiple artists and designers, so they should not be treated as a recipe that every member followed exactly.

## Brand or website example

“Schatkamer van de Stijl.” Designer Hamid Sallali describes this as a one-page, scroll-animation website made for a 2017 exhibition at Centraal Museum Utrecht. The project used sections about primary colors, simplicity, horizontal and vertical lines, rhythm, and utopia. The original website is now offline, but the designer’s Behance project page documents it and shows its design images.

The project adapts De Stijl ideas for a web page by organizing content around color, direction, and rhythm. Since only the project documentation remains, this example does not let us verify how the original site worked on phones or with assistive technology.

## Application to web design

A designer could use a grid to organize sections, with a few colored rectangles to mark important content. Headings and body text should remain easy to read, and the navigation should keep a clear order. On smaller screens, the blocks could stack vertically while preserving that order. These are possible adaptations; they are not claims that De Stijl itself prescribed modern web rules.
